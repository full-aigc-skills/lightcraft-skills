# 行为示例

以下是决策和预期契约，不是原生已验收报告。实际命令与参数须以固定运行时 discover/describe 为准。

- 成功：自然语言请求完成曝光调整并导出。按 setup→library→develop→export 路由；复用已有安装与目标 ID，交付原片、库、设置、回执及已审阅候选。
- 部分失败：导入部分成功时仅处理已确认 ID；保存失败或导出损坏分别记录，不以某一步成功代替整个任务成功。
- 恢复：任务 UNKNOWN 后交给只读 inspect/reconcile，核对进程、库和候选身份；需新会话时明确照片选择与范围，不自动继续剩余计划。
- 覆盖拒绝：用户请求新效果时先建立新输出目标。已有原片、工作库和候选的角色保持明确；拒绝原片覆盖，不宣称自动回滚。
