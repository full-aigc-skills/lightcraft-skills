## Context

批量范围与选择性修订已实施并完成实际验收；RAW 与 SAM 仍未完成。源码与固定制品能力必须分开。

## Goals / Non-Goals

Goals: 批量目标范围、相机变体与 SAM 条件。Non-Goals: 不修改基础变更验收标准，不从离线测试推导平台、RAW 或宿主通过。

## Decisions

按固定版本、执行模式、素材/制品摘要和明确目标绑定证据；复用版本化回执和任务状态，不建立第二套原生解释器。失败和 UNKNOWN 保留，外部安装/发布按对应授权。

## Risks / Trade-offs

依赖、模型或设备缺失时保留 BLOCKED/NOT_RUN；不能用新文档关闭运行门禁。

## Migration Plan

先建立失败回归，再实现并验证各门禁；兼容旧记录并保留人工修改。

## 2026-10-08 批量实施细化

批量合同显式声明 targetIds、observedIds、allowedFields，目标必须包含于观测范围。初次批量与选择性修订共享固定目标和字段边界，修订仅提交需要改变的 ID/字段。禁止隐式当前选择、布尔/重复 ID、全量设置替换及未知修改命令。控件值依当前原生 controls 的数值范围验证，不复制原生显影解释器。

计划在同一原生会话读取每张观测照片的身份和完整设置，按明确 IDs 应用局部补丁，再读取全部观测设置。核对完整设置，仅允许声明字段改变；对照照片和本轮未修订照片必须完全不变。回执绑定合同、计划、输入、资源、固定原生版本与实际步骤。失败/NotSaved/UNKNOWN 不重放，不因设置比对通过宣布视觉或最终交付通过。

插件任务以可选结构化 batchScope 启用严格门禁，旧单照片任务保持兼容。create/run/revise 均检查边界，修订声明必须是初始合同子集；不可用文字 scope 放行结构化批量任务。插件本地策略与上游算法分开，受保护技能快照不直接改写。
