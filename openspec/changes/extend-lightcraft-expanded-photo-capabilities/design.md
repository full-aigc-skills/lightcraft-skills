## Context

批量范围、选择性修订与逐样本 RAW 合同已完成实际验收；RAW 支持只覆盖所测样本，SAM 仍未完成。源码与固定制品能力必须分开。

## Goals / Non-Goals

Goals: 批量目标范围、相机变体与 SAM 条件。Non-Goals: 不修改基础变更验收标准，不从离线测试推导平台、RAW 或宿主通过。

## Decisions

按固定版本、执行模式、素材/制品摘要和明确目标绑定证据；复用版本化回执和任务状态，不建立第二套原生解释器。失败和 UNKNOWN 保留，外部安装/发布按对应授权。

## Risks / Trade-offs

依赖、模型或设备缺失时保留 BLOCKED/NOT_RUN；不能用新文档关闭运行门禁。

## Migration Plan

先建立失败回归，再实现并验证各门禁；兼容旧记录并保留人工修改。

## 2026-10-08 批量实施细化

批量合同显式声明 targetIds、observedIds、allowedFields，目标必须包含于观测范围。初次批量与选择性修订共享固定目标和字段边界，修订仅提交需要改变的 ID/字段。禁止隐式当前选择、布尔/重复 ID、全量设置替换及未知修改命令。控件值依当前原生 controls 的数值范围验证，不复制原生显影解释器。

计划在同一原生会话读取每张观测照片的身份和完整设置，按明确 IDs 应用局部补丁，再读取全部观测设置。核对完整设置，仅允许声明字段改变；对照照片和本轮未修订照片必须完全不变。回执绑定合同、计划、输入、资源、固定原生版本与实际步骤。失败/NotSaved/UNKNOWN 不重放，不因设置比对通过宣布视觉或最终交付通过。

插件任务以可选结构化 batchScope 启用严格门禁，旧单照片任务保持兼容。create/run/revise 均检查边界，修订声明必须是初始合同子集；不可用文字 scope 放行结构化批量任务。插件本地策略与上游算法分开，受保护技能快照不直接改写。

## 2026-10-08 RAW 样本身份实施

版本化 manifest 在启动原生进程之前验证每个 sampleId、制造商/型号/变体、来源/许可 URL、字节数和 SHA256，拒绝缺失元数据、重复身份及文件链接。若提供目录条目，绑定其摘要并核对相机/变体、许可和样本摘要；目录标签只证明该样本变体，不能推断同型号其他文件。

运行结果分别记录原生报告完整 RAW、明确预览回退、原生明确不支持、其他失败和未知；不得用扩展名、布尔 previewOnly、导出 PNG 或退出码推断完整 RAW。实际 camera 与样本制造商/型号必须匹配；保留制造商别名规则和原始字符串。每个样本保留原片前后摘要、固定原生/资源身份、导入/显影导出/独立重开回执。

插件只读消费带身份的逐样本结果，拒绝来源或状态矛盾，不将预览回退、环境失败或不支持转为完整 RAW 支持。实际配套验收分别运行插件受保护公开快照和当前技能源，不直接覆盖 managed skills。真实照片视觉与目标平台门禁另记，不由技术解码通过替代。


### SAM 当前增量：只读评估与明确缺口

新增独立的 SAM 模型身份评估，不改变受保护的已发布插件技能快照。固定 CLI 0.2.1 与研究主线可能存在命令差异，目录缺少状态命令时编译标记必须 UNKNOWN。模型清单固定官方 revision；权重 SHA256 来自上游配置，官方受限 API 未公开该摘要；分词文件使用官方 Git blob SHA1 检查内容并记录实际 SHA256，不宣称官方提供了 SHA256。评估不会接受许可、授权下载或执行模型，原生分割验收和任务 1.3 保持 OPEN。
