# Android 手机移动文件交付验收（2026-10-09）

实际设备 MI 9，Android 11 / API 30，1080×2340，密度 440；设备标识仅归档 SHA256。复用 2026-10-08 已验选择性重建的两套三领域产物，以当前插件 mobile-prepare/mobile-inspect 生成和复核文件交付包。未重新执行原生重建，也未升级受管技能或原生程序。

两套包各 7 个文件，共 14 个接收文件逐一在设备上计算 SHA256，与电脑端一致。保留 original.png、photo.png、layout.pdf、delivery.pdf、page.designcraft、不可改写的来源报告及清单；两套来源树的前后摘要不变。device-transfer.json 绑定原始来源报告、清单和实际设备接收摘要。bundle 中来源报告的 root 保留历史实际路径，用于追溯，不用于设备运行。

实际查看并审阅两套 photo.png（系统图库）及 delivery.pdf（WPS）的稳定屏幕，共四项通过。device-visual.json 绑定截图摘要及传输回执。WPS 首次条款和文件权限由用户本人确认；首次恢复显示其他文档的画面以及图库启动动画均未计作证据、未归档。显式以新文档方式打开本次 file URI 后才记录 PDF 通过。截图仅包含本次测试文件的查看器画面。

范围：Android 手机上的合成渐变 PNG/PDF 文件接收及显示。未安装应用，未证明平板、iOS、原生工程设备端重开/编辑、RAW 色彩保真或自动宿主跨域调度。原生工程只验证字节交付。Nikon RAW 的既有偏色 FAIL 不因本次合成图通过而改变。现有任务 1.3 曾明确保留手机/平板及完整移动交付门禁，平板等证据仍缺失，因此父任务继续 OPEN；Android 子验收已标记完成，未同步/归档整个变更。

实现：插件新增独立文件打包和只读检查入口。报告 SHA256 必须显式提供；拒绝已有目标、来源漂移、路径外逃、链接、特殊文件、缺失工程引用及多余/篡改成员，复用既有 craft-artifact 公共校验器。报告 status 不充当原生执行证明；两个入口均不连接设备、不安装、不重放原生任务、不授予视觉通过。
