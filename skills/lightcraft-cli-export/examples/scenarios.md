# 行为示例

以下是决策和预期契约，不是原生已验收报告。实际命令与参数须以固定运行时 discover/describe 为准。

- 成功：对已选照片声明格式、宽高、位深与色彩目标，导出到新目录。逐文件实际解码、测量和比较，再将候选摘要交给视觉审阅。
- 部分失败：原生退出零但一个文件损坏或尺寸不符。保留其他候选，技术状态 FAIL；配置中的预期尺寸不等于真实文件尺寸。
- 恢复：已看到导出文件但执行回执缺失时保持 UNKNOWN；只读核对文件，不把其存在作为重放或交付许可。
- 覆盖拒绝：拒绝既有文件、原片/硬链接及输出根之外路径。JPEG 16-bit 等不支持组合执行前报错，不接受静默降级。
