# 场景技能候选

新增技能位于 skills/，独立技能源维护，插件本地候选按 scenario-candidates.json 校验。既有发布快照不变。当前完成内容与实际场景视觉验收分开；尚未逐场景完成用户素材验收。

- `lightcraft-raw-develop`：RAW 基础显影（白平衡、曝光与高光阴影）
- `lightcraft-batch-photo-style`：照片批量调色（同组照片的风格统一）
- `lightcraft-landscape-develop`：风光显影（天空、地面和层次恢复）
- `lightcraft-photo-culling`：照片筛选整理（导入、评级、分组与精选）
- `lightcraft-portrait-develop`：人像自然显影（肤色、曝光和背景平衡）
- `lightcraft-photo-export`：摄影成片交付（筛选照片的尺寸、色彩与命名）
