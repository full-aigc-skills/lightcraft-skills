# 行为示例

以下是决策和预期契约，不是原生已验收报告。实际命令与参数须以固定运行时 discover/describe 为准。

- 成功：目标只要求增加曝光。读取目标照片、develop.get 基线和 controls，显式修改 light.exposure 后再查询；比较裁剪、蒙版及其他字段保持不变。
- 部分失败：部分显影已生效而保存返回 NotSaved。回执为 PERSISTENCE_UNCONFIRMED，保留内存已修改事实，不再次执行同一调整。
- 恢复：重开后设置或照片身份不一致时拒绝可编辑交付，保留两个会话回执和差异；不把当前预览当持久化证据。
- 覆盖拒绝：局部曝光请求不能执行全量 replace/reset 或未经授权批量同步。导出前仍需拒绝原片覆盖和输出冲突。
