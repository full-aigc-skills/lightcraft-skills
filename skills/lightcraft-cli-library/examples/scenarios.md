# 行为示例

以下是决策和预期契约，不是原生已验收报告。实际命令与参数须以固定运行时 discover/describe 为准。

- 成功：明确 add/copy 意图后 library.import，再 library.query 建立 ID/路径映射，选择目标 ID。第二会话查询同一持久库、照片身份和设置。
- 部分失败：imported、duplicates、failed 同时非空。保留已导入 ID、重复项及失败路径，交接可用照片，不重新导入整批。
- 恢复：库被占用时保留错误，不删锁文件、不创建同名空库。导入超时保持 UNKNOWN，先核对库和原片身份。
- 覆盖拒绝：move 会删除登记为需保持的原片时拒绝；copy 的目标位置与受保护文件冲突也不能靠事后摘要回滚。
