# Execution receipts

The public contract is schemaVersion 1. See the [Chinese contract](task-receipts.zh-CN.md) for fields, statuses and operational details.

Use bootstrap.py --no-install for a side-effect-free check. Online discovery may install the locked runtime when authorized. The CLI wrapper owns the single native deadline; logs stream to disk, step JSONL is interpreted with bounded memory, and timeouts/uncertain outcomes remain UNKNOWN without replay.

The skill source owns scripts/sync_local_snapshot.py. Consumers validate the complete source identity and managed skill inventory before synchronization. A candidate is not a published release. Native, host, visual, platform and remote CI evidence remain separate.
