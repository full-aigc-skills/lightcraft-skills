# 行为示例

以下是决策和预期契约，不是原生已验收报告。实际命令与参数须以固定运行时 discover/describe 为准。

- 成功：对实际运行时 discover，再根据当前目录 describe/check 明确命令参数。输出二进制、模式、目录与 controls 摘要；离线 catalog 仅检查计划。
- 部分失败：两步成功后第三步返回普通错误且进程非零退出。保留成功步骤，只将协议证明未执行的后续步骤列为 NOT_EXECUTED。
- 恢复：JSONL 截断、重复结果或超时留下 UNKNOWN。inspect 回执及日志，不凭零退出或文件存在推断完整执行，不自动重放。
- 覆盖拒绝：即使计划 check 通过，app.export 写向登记原片/硬链接或已有输出时仍应在启动前拒绝。
