# 行为示例

以下是决策和预期契约，不是原生已验收报告。实际命令与参数须以固定运行时 discover/describe 为准。

- 成功：只要求检查可用性时运行 bootstrap.py --no-install，报告 MISSING/READY 和平台；MISSING 时确认目录仍未创建。已有安装授权时才冷安装固定 ZIP，核对归档、二进制和安装回执。
- 部分失败：归档校验通过但二进制摘要不符。拒绝启用，保留已有目录及错误事实，不把下载完成当作安装成功。
- 恢复：另一安装器持有操作系统锁时等待；遗留 PID 文件不能证明活动。损坏安装先只读诊断，不自行覆盖修复。
- 覆盖拒绝：目标运行目录已有不匹配回执或被人工修改的文件。拒绝覆盖，报告冲突，使用经授权的新隔离目录。
