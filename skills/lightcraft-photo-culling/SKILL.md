# 照片筛选整理

## 任务起点

先读取素材，确认交付用途、目标尺寸或时长、修改范围与必要格式。能从任务和素材确定的细节直接采用合理默认值；只询问会改变结果的缺失条件。

需要可见编辑器时交给 **lightcraft-editor** 技能。独立安装：`npx skills add full-aigc-skills/lightcraft-skills --skill lightcraft-editor`。当前新增技能为本地候选，发布前使用本地配套插件，不把此安装命令当作已发布证明。

## 执行步骤

1. 按拍摄批次整理，先排除无法解码的文件。
2. 检查失焦、闭眼、严重抖动与重复构图，标记而不直接删除。
3. 在相近照片中选择表情和细节更好的版本。
4. 生成精选集合和待处理清单。

## 工具落地

使用 command_run 调用实际 LightCraft command 接口，inspect 查询 library.info。当前 Web 版没有实时 command_list；只调用已核实的版本命令。open_file 请求导入后再检查图库；输出通过浏览器导出回写工作区。

先读取实际工具 schema，再填写参数；对象或文档 ID 使用返回值。查询到的命令必须在当前后端可用。保存前选择新输出路径，保留输入。需要的算法、格式或命令不存在时说明缺口，不能用相近名称冒充。

## 结果检查

- 不得把低曝光预览误判为废片。
- 不删除原片，保留评级与筛选理由。
- 精选数量与集合内容一致。

对照用户目标检查实际内容，而不只检查进程退出码。局部编辑查看局部细节，版式任务查看整页，时间媒体查看起止与关键段。异常结果先检查当前工程，避免重复执行不可逆操作。

## 交付

返回可编辑工程、实际派生文件和简短说明：做了哪些修改、哪些步骤因当前能力未执行、需要用户判断的内容。只列真实存在且已经检查的文件。若用户随后返工，读取本次源工程并局部修改，保留已接受的内容。
